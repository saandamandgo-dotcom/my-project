DNA Modifying Enzymes

Essential tools for manipulating DNA

Taq DNA Polymerase

  • • Thermostable enzyme
  • • Essential for PCR
  • • Optimal: 72-75°C
  • • Adds 3' dA overhang

T4 DNA Polymerase

  • • 3'→5' exonuclease activity
  • • Creates blunt ends
  • • No strand displacement
  • • Probe labeling

Restriction Enzymes

Molecular scissors

Sticky vs Blunt ends

Sticky Ends

Staggered cut leaves single-strand overhangs

5'-G AATTC-3'
3'-CTTAA G-5'

Blunt Ends

Straight cut with no overhangs

5'-CCC GGG-3'
3'-GGG CCC-5'

Types of Restriction Enzymes

Type Recognition Cut Site Cofactors
Type I Asymmetric Random ATP, AdoMet, Mg²⁺
Type II Palindromic At site Mg²⁺ only
Type III Asymmetric 20-30bp away ATP, AdoMet, Mg²⁺
Type V gRNA guided PAM site Mg²⁺

Nomenclature: EcoRI

E = Escherichia (Genus)
co = coli (Species)
R = RY13 (Strain)
I = First enzyme discovered

DNA Ligase: The Molecular Glue

Function

Joins DNA strands by forming phosphodiester bonds

  • Requires ATP or NAD+
  • Repairs single-strand breaks
  • Essential for DNA replication

Ligation Conditions

Sticky Ends

37°C, 1.0-1.5 Weiss Units

Blunt Ends

14°C overnight, higher concentration

DNA Cloning Methods

1

Traditional Cloning

Uses RE + Ligase. Limitation: No internal cut sites in insert.

2

TA Cloning (PCR Cloning)

A-overhangs on insert, T-overhangs on vector

  • • Quick ligation
  • • No RE needed
  • • pGEM-T vector
Insert: 5'-...GATC A-3'
Vector: 3'-T CTAG...-5'
// A-T base pairing
3

LIC

T4 polymerase creates overhangs. No ligase needed.

4

Gibson Assembly

3 enzymes, one tube, 50°C

15-40 bp homology
Multiple fragments
Scarless
