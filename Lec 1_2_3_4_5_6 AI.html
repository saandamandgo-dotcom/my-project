Lecture 1 — Introduction to Artificial Intelligence

المحاضرة 1 — مقدمة في الذكاء الاصطناعي

What is Intelligence?

Foundations: psychology, neuroscience, mathematics, linguistics, ethics, control theory, economics.

  • Ability to solve novel problems — intelligence often measured by adaptability and problem solving.
  • Act rationally — choose actions that maximize expected achievement of goals.
  • Act like humans — Turing-inspired behavioral criterion.

What is Artificial Intelligence?

John McCarthy's concise definition: “It is the science and engineering of making intelligent machines, especially intelligent computer programs.”

Practical working definition: Intelligence is the computational part of the ability to achieve goals in the world.

Four approaches

  1. Thinking humanly
  2. Acting humanly (Turing Test)
  3. Thinking rationally (laws of thought)
  4. Acting rationally (rational agent approach)

ما هو الذكاء؟

أساسيات: علم النفس، علم الأعصاب، الرياضيات، اللغويات، الأخلاقيات، نظرية التحكم، الاقتصاد.

  • القدرة على حل المشكلات الجديدة — يقاس الذكاء بالقدرة على التكيّف وحل المشكلات.
  • التصرف بعقلانية — اختيار الأفعال التي تزيد من تحقيق الأهداف المتوقعة.
  • التصرف مثل البشر — معيار سلوكي مستوحى من تورينج.

ما هو الذكاء الاصطناعي؟

تعريف جون مكارثي: «هو علم وهندسة صنع آلات ذكية، وخاصة برامج حاسوبية ذكية.»

تعريف عملي: الذكاء هو الجزء الحاسوبي من القدرة على تحقيق الأهداف في العالم.

أربع مقاربات

  1. التفكير البشري
  2. التصرف البشري (اختبار تورينج)
  3. التفكير العقلاني (قوانين التفكير)
  4. التصرف العقلاني (نهج الوكيل العقلاني)

Systems that Act Like Humans

Turing Test (Imitation Game): an interrogator communicates via text with a hidden human and a hidden machine. If the interrogator cannot reliably tell which is which, the machine is said to pass.

The Chinese Room (Searle)

Thought experiment arguing that syntactic symbol manipulation (running a program) is not sufficient for semantic understanding.

Strong vs Weak AI

Weak AI: machines simulate intelligence. Strong AI: machines actually have minds, understanding, and consciousness.

أنظمة تتصرف مثل البشر

اختبار تورينج: محاور يتواصل نصياً مع إنسان وآلة مخفيين. إذا لم يستطع المحاور التمييز بينهما، تُعتبر الآلة قد نجحت.

الغرفة الصينية (سيرل)

تجربة فكرية تقول إن معالجة الرموز الشكلية وحدها لا تكفي للفهم الدلالي.

الذكاء القوي مقابل الضعيف

Lecture 2 — Intelligent Agents & Related Disciplines

المحاضرة 2 — الوكلاء الأذكياء والتخصصات المرتبطة

Intelligent Agent (Rational Agent)

An agent perceives its environment via sensors and acts via actuators. A rational agent chooses actions expected to maximize its performance measure given percepts and built-in knowledge.

PEAS framework

Performance measure, Environment, Actuators, Sensors — used to specify task environments.

Examples

  • Vacuum agent — percepts: [location, status]; actions: {Left, Right, Suck, NoOp}.
  • Autonomous taxi (PEAS): Performance = safe, fast, legal, comfortable; Environment = roads, traffic; Actuators = steering, throttle; Sensors = cameras, LIDAR, GPS.

Goal-based vs Cost-based agents

Goal-based agents plan to reach a goal state. Cost-based agents minimize expected long-term cost (e.g., spam filter with weighted false positive/negative costs).

الوكيل الذكي (الوكيل العقلاني)

الوكيل يستشعر البيئة عبر حساسات ويتصرف عبر محركات. الوكيل العقلاني يختار الأفعال التي تتوقع تعظيم مقياس الأداء بناءً على المدركات والمعرفة المدمجة.

إطار PEAS

Pمقياس الأداء، Eالبيئة، Aالمحركات، Sالحساسات — لتحديد بيئة المهمة.

أمثلة

  • وكيل المكنسة — المدركات: [الموقع، الحالة]; الأفعال: {يسار، يمين، شفط، لا شيء}.
  • تاكسي ذاتي (PEAS): الأداء = آمن، سريع، قانوني، مريح؛ البيئة = الطرق، المرور؛ المحركات = عجلة القيادة، دواسة؛ الحساسات = كاميرات، ليدار، GPS.

وكلاء قائمون على الهدف مقابل قائمون على التكلفة

وكلاء الأهداف يخططون للوصول إلى حالة هدف. وكلاء التكلفة يقللون التكلفة المتوقعة على المدى الطويل (مثل فلتر البريد المزعج مع أوزان للأخطاء).

Lecture 3 — Problem Solving by Search & State Space

المحاضرة 3 — حل المشكلات بالبحث وفضاء الحالة

Search Problem Components

  • Initial state
  • Actions
  • Transition model
  • Goal test
  • Path cost (sum of step costs)

State space

Set of all states reachable from the initial state by any sequence of actions. Represented as a directed graph.

Examples

  • Romania problem — cities as states, roads as actions, distances as costs.
  • 8-puzzle — 9 positions, 8 tiles; actions: move blank up/down/left/right; path cost = number of moves.
  • Vacuum world — agent location + dirt status; actions: Left, Right, Suck.

مكونات مشكلة البحث

  • الحالة الابتدائية
  • الأفعال
  • نموذج الانتقال
  • اختبار الهدف
  • تكلفة المسار (مجموع تكاليف الخطوات)

فضاء الحالة

مجموعة كل الحالات الممكن الوصول إليها من الحالة الابتدائية عبر أي تسلسل من الأفعال. يُمثل كرسوم موجهة.

أمثلة

  • مشكلة رومانيا — المدن حالات، الطرق أفعال، المسافات تكاليف.
  • لغز 8 — 9 مواضع، 8 قطع؛ الأفعال: تحريك الفراغ؛ تكلفة المسار = عدد الحركات.
  • عالم المكنسة — موقع الوكيل + حالة الأوساخ؛ الأفعال: يسار، يمين، شفط.

Tree Search Outline (pseudocode)

function TreeSearch(start) {
  // frontier: nodes to expand
  frontier = [makeNode(start)];
  explored = {};
  while (frontier not empty) {
    node = select(frontier); // strategy dependent
    if (goalTest(node.state)) return solution(node);
    explored.add(node.state);
    for each action in actions(node.state) {
      child = childNode(node, action);
      if (child.state not in explored and not in frontier) frontier.add(child);
    }
  }
  return failure;
}

Lecture 5 — Blind (Uninformed) vs Heuristic (Informed) Search

المحاضرة 5 — البحث غير الموجه مقابل البحث الموجه

Uninformed (Blind) Search

  • Breadth-First Search (BFS) — explores level by level; guarantees shortest path when step cost = 1; time O(b^d), space O(b^d).
  • Depth-First Search (DFS) — explores deep first; low memory O(bd) but may not find shortest path and can get stuck in infinite paths.
  • Depth-Limited & Iterative Deepening — DFS with cutoff; iterative deepening combines DFS space efficiency with BFS completeness.
  • Uniform-Cost Search (UCS) — expands lowest path-cost node first; optimal when step costs ≥ 0.
  • Bidirectional Search — search forward from start and backward from goal; can reduce complexity to O(b^{d/2}).

البحث غير الموجه

  • بحث عرضي (BFS) — يستكشف مستوى بمستوى؛ يضمن أقصر مسار عندما تكون تكلفة الخطوة = 1؛ الزمن O(b^d)، الذاكرة O(b^d).
  • بحث عمقي (DFS) — يستكشف إلى العمق أولاً؛ ذاكرة منخفضة O(bd) لكنه قد لا يجد أقصر مسار وقد يدخل في حلقات لا نهائية.
  • الحد العمقي والتعمق التكراري — DFS مع حد؛ التعمق التكراري يجمع بين كفاءة الذاكرة والاكتمال.
  • بحث بتكلفة موحدة (UCS) — يوسع العقدة ذات أقل تكلفة مسار؛ مثالي عندما تكون تكاليف الخطوات ≥ 0.
  • بحث ثنائي الاتجاه — بحث أمامي وخلفي؛ يقلل التعقيد إلى O(b^{d/2}).

Heuristic (Informed) Search

Define heuristic function h(n) estimating cost from node n to goal. Examples for 8-puzzle:

  • h1: number of misplaced tiles.
  • h2: sum of Manhattan distances (admissible).

A* uses f(n) = g(n) + h(n) and is optimal if h is admissible.

البحث الموجه (الاسترشادي)

دالة الاستدلال h(n) تقدّر تكلفة الوصول من العقدة n إلى الهدف. أمثلة للغز 8:

  • h1: عدد القطع في غير مكانها.
  • h2: مجموع مسافات مانهاتن (قابلة للقبول).

خوارزمية A* تستخدم f(n) = g(n) + h(n) وتكون مثالية إذا كانت h قابلة للقبول.

Lecture 6 — Adversarial Search (Games)

المحاضرة 6 — البحث التنافسي (الألعاب)

Minimax

Two-player zero-sum games: MAX chooses moves to maximize utility; MIN chooses to minimize MAX's utility. Minimax value computed recursively: value(node) = max(children) for MAX nodes, min(children) for MIN nodes.

Alpha-Beta Pruning

Alpha = best already explored option along path to root for MAX (lower bound). Beta = best for MIN (upper bound). Prune when alpha ≥ beta. Produces same move as minimax but explores fewer nodes.

مينيمكس

ألعاب ثنائية اللاعبين مجموعها صفر: MAX يحاول تعظيم المنفعة؛ MIN يحاول تقليلها. قيمة المينيمكس تحسب بشكل تكراري: قيمة العقدة = أقصى قيمة للأبناء لعقد MAX، وأدنى قيمة لعقد MIN.

قطع ألفا-بيتا

ألفا = أفضل خيار معروف لمسار الجذر لـ MAX (حد أدنى). بيتا = أفضل خيار لـ MIN (حد أقصى). نقطع الشجرة عندما يكون alpha ≥ beta. تعطي نفس نتيجة المينيمكس مع عدد أقل من العقد.

When to use search techniques?

  • Search is appropriate when no closed-form solution exists and the search space is manageable or good heuristics exist.
  • Alternative techniques: simulated annealing, genetic algorithms, swarm intelligence for large or continuous spaces.

Exercises & Practice Problems

تمارين وأسئلة تدريبية
Q1 (English)
Describe the Turing Test and give one modern critique. Hint: Chinese Room
Answer (short): The Turing Test asks whether a machine's text responses are indistinguishable from a human's. A critique: passing the test shows behavioral equivalence but not necessarily understanding (Searle's Chinese Room).
الإجابة (مختصرة): اختبار تورينج يقيس ما إذا كانت ردود الآلة النصية لا تميز عن ردود الإنسان. النقد: النجاح السلوكي لا يعني الفهم الدلالي (غرفة الصينية لسيرل).
Q2 (English)
For the 8-puzzle state below, compute h1 (misplaced) and h2 (Manhattan).
Start state:
2 8 3
1 6 4
7 _ 5
Solution: h1 = count misplaced tiles = 5 (tiles 2,8,3,6,5 are misplaced). h2 = sum Manhattan distances = compute each tile distance to goal positions (example: tile 2 distance 1, tile 8 distance 2, ... ) → total = 10 (example value; compute precisely in class).
الحل: h1 = عدد القطع في غير مكانها = 5. h2 = مجموع مسافات مانهاتن = احسب مسافة كل قطعة إلى موقعها النهائي → المجموع = 10 (قيمة توضيحية).
Q3 (English)
Formalize the Missionaries and Cannibals problem as a state-space search (state representation, initial, goal, operators).
Solution sketch: State = (M_left, C_left, boat_side). Initial = (3,3,Left). Goal = (0,0,Right). Operators: move 1 or 2 people across (combinations of M and C) with constraint: on each bank, M >= C or M=0. Path cost = number of crossings.
مخطط الحل: الحالة = (عدد المبشرين على اليسار، عدد آكلي البشر على اليسار، جانب القارب). الابتدائية = (3,3,يسار). الهدف = (0,0،يمين). المشغلات: نقل 1 أو 2 أشخاص مع قيد: في كل ضفة يجب أن يكون المبشرون ≥ آكلي البشر أو المبشرون = 0. تكلفة المسار = عدد العبور.
