The Turing Test (1950)

اختبار تورينج (١٩٥٠)

EN

The Imitation Game: Can a human interrogator tell whether written responses come from a human or a machine? If the machine can fool the interrogator, it passes the test.

Capabilities Required:

  • Natural Language Processing
  • Knowledge Representation
  • Automated Reasoning
  • Machine Learning
ع

لعبة التقليد: هل يمكن للمحقق البشري التمييز بين الردود المكتوبة القادمة من إنسان أو آلة؟ إذا استطاعت الآلة خداع المحقق، فإنها تجتاز الاختبار.

القدرات المطلوبة:

  • ▸ تمثيل المعرفة

The Chinese Room Argument (Searle, 1980)

حجة الغرفة الصينية (سيرل، ١٩٨٠)

EN

A person in a room follows English instructions to manipulate Chinese symbols. To outside observers, the room appears to understand Chinese, but the person inside has no understanding.

Conclusion: Syntax (symbol manipulation) ≠ Semantics (understanding)

Strong AI: Machines can truly understand (consciousness)

Weak AI: Machines only simulate understanding

ع

شخص في غرفة يتبع تعليمات إنجليزية للتعامل مع الرموز الصينية. للمراقبين من الخارج، تبدو الغرفة تفهم الصينية، لكن الشخص داخلها لا يفهم.

الاستنتاج: الصياغة (معالجة الرموز) ≠ الدلالة (الفهم)

الذكاء الاصطناعي القوي: الآلات يمكنها الفهم الحقيقي (الوعي)

الذكاء الاصطناعي الضعيف: الآلات تحاكي الفهم فقط

Three Stages of AI | مراحل الذكاء الاصطناعي الثلاث

A* Search Algorithm

خوارزمية البحث A*

f(n) = g(n) + h(n)

g(n) = cost from start to node n | التكلفة من البداية للعقدة n
h(n) = heuristic estimate from n to goal | التقدير الاستدلالي من n للهدف
f(n) = estimated total cost | إجمالي التكلفة المقدرة

Properties | الخصائص:
• Complete: Yes (if branching factor finite) | كاملة: نعم
• Optimal: Yes (if h(n) is admissible) | أمثل: نعم (إذا كانت h(n) مقبولة)
• Admissible: h(n) ≤ h*(n) never overestimates | مقبولة: لا تبالغ أبداً
↩️

Backtracking Search

البحث بالتتبع العكسي

EN

Systematically tries all paths through state space. When a dead end is reached, backtracks to the most recent unexamined node.

Data Structures:

  • SL: State List (current path)
  • NSL: New State List (nodes to explore)
  • DE: Dead Ends (failed paths)
  • CS: Current State
ع

يحاول جميع المسارات عبر فضاء الحالات بشكل منهجي. عند الوصول إلى طريق مسدود، يعود إلى أحدث عقدة غير مفحوصة.

هياكل البيانات:

  • ▸ SL: قائمة الحالات (المسار الحالي)
  • ▸ NSL: قائمة الحالات الجديدة (للاستكشاف)
  • ▸ DE: الطرق المسدودة (المسارات الفاشلة)
  • ▸ CS: الحالة الحالية
